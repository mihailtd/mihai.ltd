# GitLab

Previously adopted for source control and CI/CD. Rejected in favor of [GitHub](/blog/github) — mainly because GitHub Projects and Issues, especially paired with GitHub Copilot for agentic project management, pulled ahead on AI-friendliness. CI/CD and private repositories were roughly equivalent between the two.
