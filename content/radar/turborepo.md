# Turborepo

Task runner and build system for [monorepos](/blog/monorepo), with caching and parallel execution. Hyper-optimized for the pure JavaScript/TypeScript ecosystem, with no native awareness of Python — likely the wrong fit for a repo that mixes Python and Node.js, but kept in the comparison for completeness against [Moon](/blog/moon) and [Nx](/blog/nx).

Genuinely liked, though — for a pure JS/TS monorepo with no other languages in the mix, this would be the pick over Nx.
