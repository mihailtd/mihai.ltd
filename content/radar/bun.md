# Bun

Trialing Bun for its speed and built-in tooling (bundler, test runner, package manager). Not yet trusted for production workloads where Node's ecosystem maturity still wins. Where it is used, Bun manages its own packages — [pnpm](/blog/pnpm) is for Node/TypeScript projects, Bun handles Bun projects itself.
